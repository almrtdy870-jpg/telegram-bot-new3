# 🦅 بوت صيد يوزرات تليجرام

بوت تليجرام يولّد يوزرات حسب النمط اللي تختاره، ويفحص إذا متاحة، ويبلّغك فوراً، وإذا تريد يثبّتها تلقائياً على حسابك.

## المميزات
- **أنواع جاهزة**: خماسي، خماسي مختلط، سداسي، شبه ثلاثي (`a_b_c`)، شبه رباعي، مكرر، حرف ثلاثي مكرر، ينلفظ، حرف + أرقام، حروف + رقم.
- **قوالب مخصصة**: `L` حرف، `D` رقم، `X` حرف/رقم، `V` حرف علة، `C` حرف ساكن، `=` تكرار الحرف السابق، وأي حرف صغير أو رقم يُكتب كما هو (مثال `iraqLL`).
- **قائمة كلمات**: ترسلها نص أو ملف `.txt`، ومعها **تنويعات** تلقائية (`lionx`, `thelion`, `l_ion` ...).
- **بادئة / لاحقة** تنضاف لكل يوزر.
- **فحص متعدد الطبقات**:
  1. صفحة `t.me` (سريع، يستبعد المحجوز).
  2. حسابك عبر Telethon `account.checkUsername` (دقيق 100%) — إذا ربطت حساب.
  3. `fragment.com` يكشف اليوزرات المباعة أو المعروضة بالمزاد.
- **تثبيت تلقائي** (اختياري): على **قناة جديدة** لكل يوزر، أو على **حسابك** نفسه.
- خيوط متوازية + تأخير قابل للتعديل + حد أقصى للفحص + تبطيء تلقائي عند الحظر المؤقت، ويحترم FloodWait.
- رسالة حالة حيّة (المفحوص، المتاح، السرعة/دقيقة، المدة) تتحدث كل 20 ثانية.
- فحص سريع: أرسل `@username` أو زر 🔍 لفحص حتى 50 يوزر.
- حفظ اليوزرات المصادة وتصديرها كملف.
- البوت **خاص**: يا هو `ADMIN_IDS`، أو أول شخص يرسل `/start` يصير هو المالك.

## متغيرات البيئة
| المتغير | مطلوب | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت من @BotFather |
| `ADMIN_IDS` | | آيديات المسموح لهم، مفصولة بفاصلة |
| `API_ID` / `API_HASH` | | من https://my.telegram.org (للفحص الدقيق والتثبيت) |
| `TG_SESSION` | | الجلسة النصية، تطلع من `python gen_session.py` |
| `WEBHOOK_URL` | | مثل `https://my-bot.onrender.com` لتشغيله بالويب هوك، وإذا ما حطيته يشتغل polling |
| `DATA_FILE` | | مسار ملف البيانات (الافتراضي `data/hunter.json`) |

## التشغيل
```bash
pip install -r requirements.txt
export BOT_TOKEN=xxxx
python hunter_bot.py            # polling (VPS أو جهازك)
```
على Render (Web Service):
- Build: `pip install -r requirements.txt`
- Start: `gunicorn hunter_bot:app --workers 1 --threads 16`
- حط `WEBHOOK_URL` برابط الخدمة.
- لازم **worker واحد بس**، لأن حالة الصيد محفوظة بالذاكرة.

> ⚠️ قرص Render المجاني مؤقت: ملف البيانات ينمسح مع كل نشر، فصدّر صيدك أول بأول.

## ملاحظات
- لا تعطي `TG_SESSION` لأي أحد، لأنه يعطي تحكم كامل بحسابك.
- إذا كثّرت الخيوط والسرعة، `t.me` يحظر الآيبي مؤقتاً وتليجرام يعطي FloodWait للحساب. الأنسب 3-10 خيوط وتأخير 0.3-1 ثانية.
- اليوزرات 4 أحرف وأقل تنباع بس على Fragment، وما تكدر تثبتها مجاناً.
