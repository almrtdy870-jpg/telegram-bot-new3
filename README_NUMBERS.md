# 📱 بوت مورد أرقام

بوت تليجرام يبيع أرقام وهمية لاستلام كود التفعيل (تليجرام، واتساب، جوجل...). البوت يشتري الرقم من **5sim.net** ويبيعه للزبون بسعرك، والفرق ربحك.

## شلون يشتغل
1. الزبون يشحن رصيد عندك (تحويل/كارت... بالطريقة اللي تريدها) وأنت تضيفله الرصيد من لوحة الأدمن.
2. يختار الخدمة ← الدولة (مرتبة من الأرخص) ← يشتري.
3. البوت يخصم السعر ويعطيه الرقم، وأول ما يوصل الكود يبعثه إله تلقائياً.
4. إذا ما وصل كود خلال 20 دقيقة، أو إذا الزبون لغى الطلب، **يرجعله رصيده كامل** تلقائياً.

## لوحة الأدمن (`/admin` أو زر ⚙️)
- إحصائيات: المستخدمين، الأرقام المباعة، المبيعات، رصيدك بـ 5sim.
- ➕ إضافة / ➖ خصم رصيد (أو بالأوامر `/add 123456789 5` و `/take 123456789 5`).
- 📈 **معامل التسعير**: سعر البيع = سعر 5sim بالروبل × المعامل. مثال: المعامل `0.02`، الرقم بـ 5sim يكلف 10₽ ≈ 0.11$، فتبيعه بـ 0.20$.
- 🏷 سعر ثابت لخدمة ودولة معينة: `telegram russia 0.5`.
- 🔻 أقل سعر بيع، 💱 رمز العملة، 💳 كليشة الشحن، 📢 إذاعة، 🚫 حظر، ⛔ إيقاف البوت للصيانة.

## التجهيز
1. سوّي بوت من **@BotFather** وخذ التوكن.
2. سجّل بـ **5sim.net**، اشحن رصيد، ومن Profile ← API key خذ المفتاح (Bearer token).
3. خذ الآيدي مالتك من **@userinfobot**.

## متغيرات البيئة
| المتغير | مطلوب | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت |
| `FIVESIM_TOKEN` | ✅ | مفتاح API من 5sim |
| `ADMIN_IDS` | ✅ | آيدي الأدمن (أكثر من واحد بفاصلة) |
| `WEBHOOK_URL` | | رابط الخدمة على Render، وبدونه يشتغل polling |
| `NUMBERS_DATA` | | مسار ملف البيانات (الافتراضي `data/numbers.json`) |

## التشغيل
```bash
pip install -r requirements.txt
export BOT_TOKEN=xxx FIVESIM_TOKEN=yyy ADMIN_IDS=123456789
python numbers_bot.py
```
على **VPS** (الأفضل): نفس الأوامر فوق، مع `screen` أو `systemd` حتى يبقى شغّال.

على **Render**:
- Build: `pip install -r requirements.txt`
- Start: `gunicorn numbers_bot:app --workers 1 --threads 8`
- حط `WEBHOOK_URL` برابط الخدمة.

> ⚠️ **مهم**: أرصدة الزباين محفوظة بملف `data/numbers.json`. قرص Render المجاني ينمسح مع كل نشر، فلازم تستخدم **VPS** أو **Render Disk** مدفوع (وتخلي `NUMBERS_DATA` على مسار الديسك)، وإلا تضيع أرصدة الزباين.

## ملاحظات
- لا تعطي `FIVESIM_TOKEN` لأحد، لأن بيه رصيدك بالمورد.
- خلي رصيدك بـ 5sim دايماً مشحون، لأن إذا خلص يطلع للزبون "رصيد المورد خلص" (ورصيده ما يتأثر).
- التزم بشروط 5sim وقوانين بلدك، ولا تبيع الأرقام لاستخدامات احتيالية.
